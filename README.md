This project focuses on predicting students' academic outcomes using Machine Learning classification algorithms. The analysis uses the Predict Students' Dropout and Academic Success dataset obtained from the UCI Machine Learning Repository. The main objective is to develop and compare two Machine Learning classification models: Decision Tree Classifier Logistic Regression Both models are used to predict whether a student will Graduate, Dropout, or remain Enrolled. By comparing their performance, this project aims to identify which algorithm provides more reliable predictions of student academic outcomes.
